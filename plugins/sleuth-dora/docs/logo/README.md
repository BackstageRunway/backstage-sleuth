# Logo

The Backstage Runway logo, for places that list the plugin.

| File                                    | Use it                                                                       |
| --------------------------------------- | ---------------------------------------------------------------------------- |
| `backstage-runway-icon-sky.svg`         | As a square icon. White mark on sky blue; reads well on light and dark pages |
| `backstage-runway-icon.svg`             | As a square icon on a light page. Sky blue mark on navy                      |
| `backstage-runway-wordmark-dark.svg`    | The name in navy, for a light background                                     |
| `backstage-runway-wordmark-white.svg`   | The name in white, for a dark background                                     |
| `backstage-runway-wordmark-on-navy.svg` | The name in white on its own navy panel                                      |

The icon files ship in the npm package, so they have a public address once a version is published, for
example:

`https://cdn.jsdelivr.net/npm/@backstagerunway/plugin-sleuth-dora/docs/logo/backstage-runway-icon-sky.svg`
